Источник данных

Сейчас админка работает на демо-данных из статических JSON. Подключение к API master ещё не выполнено.

  • data/rtc.json — текущее время
  • data/week.json — недельное расписание (7×24)
  • data/channels.json — реестр 16 каналов
  • data/ina.json — показания INA3221 и история за 24 ч
Для перехода на реальные данные достаточно заменить методы в js/data-source.js — структура ответа остаётся прежней.

Оформление

Тема интерфейса сохраняется в браузере.

Разделы

  • Обзор — сводка по времени, заданию и INA
  • Расписание — сетка 7×24
  • Каналы — реестр каналов и клапанов
  • INA — напряжения, токи, история
  • Время — часы DS3231 (демо)

Служебное

Сброс офлайн-кэша помогает, если после обновления файлов браузер показывает старую версию.
